# Project Vision

## Purpose

Mission Dawah South Africa is an NGO website for communicating the work of two core projects: a feeding scheme and a bursary program. The site should make the organization clear, credible, and easy to contact.

This project also serves as a practical DevOps learning project for the developer, a fourth-year part-time student and full-time .NET/Blazor/Azure developer.

## Learning Vision

The project should help the developer grow through deliberate practice, not only produce a finished site. Prioritize understanding over speed when tradeoffs arise. Use each feature to strengthen knowledge of Nuxt, Vue, TypeScript, TDD, CI/CD, deployment, SEO, and later .NET backend integration.

AI assistance should be used as leverage for learning: explain decisions, compare concepts to familiar .NET/Blazor patterns when helpful, and support repeated explanations until the underlying ideas are understood.

Respect the developer's limited review time: start each feature with a three-line plan and get one approval for the agreed work. Complete the TDD implementation and checks autonomously, then provide a concise handoff for review by another Codex before the PR. Offer deeper explanations when requested; learning should not require approving every action or reading every line of code.

## Direction

- Present the project clearly to visitors.
- Make key information easy to find on mobile and desktop.
- Support future content about the feeding scheme and bursary program.
- Add static pages first, then backend-powered contact and donation features.
- Keep the codebase simple enough to evolve quickly.

## Principles

- Serve the audience first.
- Prefer clear navigation and readable content.
- Build features incrementally.
- Keep deployment and maintenance straightforward.

## Open Questions

- What exact content should appear on the feeding scheme and bursary pages?
- Who are the primary user groups: donors, applicants, volunteers, or beneficiaries?
- What content needs regular updates, such as events, announcements, or impact reports?
